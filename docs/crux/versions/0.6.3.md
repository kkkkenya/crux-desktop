# Crux Harness 0.6.3

## Done

- **Update now, no installer.** When a new version only changes what runs inside the window, Crux Harness offers "Update now": it downloads the update, checks that it is the signed release, installs it in place and restarts by itself. Your sessions and notes stay. An update that fails to start is switched off on its own and the installed version runs again. Versions that change the window itself still come as an installer.
- **Several Hub files at once.** Tick the files you want and choose "Add N to session"; any you have not downloaded yet download first.
- **No more "0 pages".** A Hub file whose page count Crux does not know shows no count.
- **Checked solutions pack.** For a unit with checked solutions (EMM 302 for now), the tutor reads `<unit> checked solutions.md` in the unit's Hub folder as the answer key and teaches the free body diagram first.
