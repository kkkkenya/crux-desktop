# Crux Harness 0.6.4

## Done

- **Marking schemes, in the left bar.** Pick a unit and see its marking schemes, each beside the paper it marks. One click opens the scheme, with no lesson around it. Opening a scheme never uses one of your downloads. A paper with no scheme yet has "Ask for the scheme", which tells the Hub admin. Schemes the tutor made for you are listed too. The same list is on Crux web, under Schemes on each unit.
- **Ask the tutor about a passage.** Select text in a paper, notes or a marking scheme and choose Ask the tutor. The passage goes into your message with its file and page, and you add your question.
- **No access yet?** The sign-in screen explains how to get in: join the Study Hub, pay in #plans and press I've paid, then an admin checks your account.
- **Files, in the top bar of every session.** Your unit's past papers, notes and marking schemes. Each opens inside Crux in its own tab, like on Crux web.
- **Collapse to keep reading.** Collapse a file and its page stays small and live at the top of your notes, with page arrows and Continue reading. Open files and the page you were on are kept for next time. Each file loads once.
- **Add to notes.** Select text in a PDF or a marking scheme and choose Add to notes. The note goes to that unit, with the file and page.
- **Marking schemes with free body diagrams.** Ask the tutor for a marking scheme or a full solution to keep. It writes one page in the EMM 302 marking-scheme format: free body diagrams first, then the formula, the substitution, the answer with units, a check and a marks table. The page is saved in the unit's Hub folder under Solutions and opens as a tab.
- **Safer pages.** A marking scheme runs no code of its own. Crux removes any script in it and allows only MathJax for the equations.
- **The tutor teaches the free body diagram first** in mechanics questions, and checks every answer a second way.
