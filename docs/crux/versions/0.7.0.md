# Crux Harness 0.7.0

A new installer: download it from Crux web and run it over your current version.

## Done

- **Hub files desk** (server staff only). A new button on the left. Choose files, set the unit, the kind (past paper, marking scheme, notes, tutorial, slides, book) and the year, and Drop puts them into the drive dumper's Drop folder in Google Drive, named so each lands in its unit's post. Files already on the Hub are spotted first and skipped. The desk also shows what's waiting, what failed and why (with Retry), what was posted lately with links, the files in #to-sort with a picker to sort each one, and students' uploads with where each one is.
- **Sharing with your class** takes several files at once, asks what each is and its year, and skips files the Hub already has.
- **Later features as updates.** Crux Harness can now reach more of Crux web, so the next features (Today, the done bar, the scheme dumper) arrive with Update now instead of a new installer.
