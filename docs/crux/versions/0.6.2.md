# Crux Harness 0.6.2

## Done

- **New name: Crux Harness.** The app, its window, shortcuts and installer are called Crux Harness. Your sessions, notes and settings stay where they were (`%APPDATA%\Crux`), so nothing needs moving. Installing 0.6.2 removes the old "Crux" install first and reuses its folder.
- **Faster install.** The installer unpacks files straight into the install folder. Before, it unpacked about 6,600 files to a temporary folder and then copied each one again with no progress shown, which is why it looked stuck near the end. Measured on this laptop: a silent install over 0.6.1 takes 132 seconds, removing the old version included, and the first start after it about 60 seconds.
- **Programming units.** In units like EMM 308, the tutor writes code with only what your notes use, keeps comments out of the code, and explains each part after the code block. A better way that was not taught can come last, marked as not for the exam. `057802ba`
