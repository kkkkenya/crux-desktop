# Crux Harness 0.8.1

Gemini 4 Hydrogen, PDFs that DeepSeek can read, easier files and renaming.

## Done

- **Gemini 4 Hydrogen** replaces Gemini 3.8 Flash. Sessions on 3.8 Flash open on Hydrogen.
- **Fewer Gemini errors.** Gemini chats that use tools no longer fail on the second turn. When Gemini is busy, an older Gemini answers instead (this part is on Crux's side and works in every version).
- **PDFs with DeepSeek.** DeepSeek reads text only, so Crux reads a PDF's text for it and sends the pictures to Gemini when your plan has it. When a PDF can't be read (a scan, a password, a damaged file, pictures skipped), Crux says so in one plain sentence. The same goes for notes import and figures drawn from a PDF page.
- **The PDF viewer** shows a plain message for a password-protected or damaged file, and "This page could not be drawn" instead of a blank page.
- **Files.** Hub files sort by name in the order you'd expect (CAT 2 before CAT 10), papers first, or files on this computer first, and Crux remembers your choice. Select all. Session documents sort by name or recently added. Adding a file twice or the wrong type now says why it was skipped.
- **Paste and drop.** Ctrl+V pastes a copied file into the message box. Drop files anywhere in the window to add them to the session.
- **Rename a session** by double-clicking it, pressing F2, or the pencil. A session started with documents only takes its name from your first message.
- **Free-body diagrams** follow stricter rules (every force from its point, supports replaced by reactions, distributed loads with their resultant) and are checked before they're shown. Under each figure, **Copy image prompt** gives a ready prompt for Gemini or another image AI.
