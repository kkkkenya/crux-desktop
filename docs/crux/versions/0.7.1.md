# Crux Harness 0.7.1

An update: Crux Harness offers it with Update now. No new installer.

## Done

- **Updates without the browser.** Crux Harness checks for a new version when it opens and every six hours. When one is ready, a green bar says so; tap Restart and Crux Harness updates and opens again by itself. A version that needs a new installer is downloaded quietly in the background and installed with no clicks, so there is no GitHub page and no Windows warning.
- **The Crux logo** plays the first time Crux Harness opens after setup or an update. Tap it or press Esc to skip.
- **DeepSeek first.** New sessions start on DeepSeek Flash. A session or a model setting still on GLM (paused) opens on DeepSeek Flash instead of a model Crux no longer offers.
- **Clear errors.** When a model can't answer, you see one sentence and what to do: try again, wait a few minutes, start a new session or pick another model. If a model is busy or out of credit, Crux moves to the next one by itself and says so once.
- **Sharing with your class** keeps the kind, year and extension of a long file name, so the file is no longer turned away as the wrong type. Files with curly quotes, dashes, accents or emoji in the name now upload (fixed on Crux web).
- **The reader** shows every page in its own shape. Pages that differ from the first one (a sideways cover, photos joined into one PDF) were squashed.
