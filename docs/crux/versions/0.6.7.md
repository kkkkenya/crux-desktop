# Crux Harness 0.6.7

An update: press Update now in Crux Harness.

## Done

- **Code, while you study.** The Code button in a session's top bar opens a panel beside the lesson. Write Python, SQL or JavaScript and run it here, with nothing to install. SQL results show as a table. Ask the tutor puts your code, its output and any error into your message. Ctrl+Enter runs. Each language loads the first time you use it.
- **Voice in study rooms.** The host can add a Discord voice channel in Room settings, and everyone in the room gets Join voice, which opens it in Discord. Only the room's members can see the channel, and it goes when the room ends. In the call, Share Your Screen shows your working; the board uses far less data.
